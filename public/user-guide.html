HOW TO USE SANZ AI SYSTEM

Complete User Guide
For Beginners

Learn how to login, register users, start AI live scanning, mark attendance, and manage the dashboard using SANZ SecureFace AI system step-by-step.

🔐

STEP 1 — LOGIN SYSTEM

Open SANZ SecureFace AI login page. Enter admin email and password correctly. After successful authentication, dashboard opens automatically.

👤

STEP 2 — REGISTER NEW USER

Open Register page from dashboard. Enter student or employee name and upload clear face image. AI system stores facial data securely.

📷

STEP 3 — START LIVE SCAN

Open Live Scan page and allow camera access. AI detection system automatically starts scanning faces in real-time.

🧠

STEP 4 — FACE VERIFICATION

AI compares detected face with registered database and verifies user identity using deep learning technology.

📊

STEP 5 — ATTENDANCE MARKING

When face match is successful, attendance is automatically marked and saved inside dashboard records.

⚙️

STEP 6 — MANAGE DASHBOARD

Dashboard allows admins to view attendance history, registered users, analytics, and system activity instantly.

System Tips

📷 Better Detection

Use proper lighting and keep face clearly visible for accurate AI recognition.

⚡ Faster Performance

Use Chrome browser and stable internet connection for smooth experience.

🔒 Security

Do not share admin credentials and regularly update registered data.

📱 Mobile Support

Install SANZ AI as PWA app for better mobile experience and offline support.

Frequently Asked Questions

Why is camera not opening?

Allow browser camera permission and refresh the page once.

Why face is not detecting?

Improve lighting conditions and keep your face centered inside camera frame.

Can attendance be edited?

Yes. Admin users can manage attendance records through dashboard panel.

Does system support mobile devices?

Yes. SANZ SecureFace AI works on Android, Windows, Chrome, and Edge browsers.
